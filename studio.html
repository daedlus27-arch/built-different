Publishing a post

  1. Chrome or Edge: click Save to posts folder and pick the content/posts folder inside your site the first time. Studio writes the post file and updates _list.js for you. Reload the blog. Done.
  2. Any other browser: click Download, move the file into content/posts, then download the updated _list.js and replace the old one.

Editing an old post

Pick it from Edit an existing post…, change what you want and save again. Changing the date or slug renames the file.
